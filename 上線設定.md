# 中秋烤肉登記上線設定

## 1. 先處理已暴露的金鑰

先到 Google Cloud Console 撤銷並重新建立先前貼出的 Service Account private key。那份私鑰不可以放進 GitHub、HTML 或前端 JavaScript。

## 2. 建立 Firebase Web App

1. 開啟 Firebase Console，選取專案 `bbq-88bd2`。
2. 到 Project settings > Your apps > Web，建立 Web App。
3. 複製 Firebase SDK 設定中的 `apiKey`、`messagingSenderId`、`appId`。
4. 到 Realtime Database 建立資料庫，複製實際的 `databaseURL`。
5. 將這四個值填入 `中秋烤肉登記.html` 內的 `firebaseConfig`。

Firebase Web API key 可以出現在前端；Service Account private key 絕對不可以出現。

## 3. 開啟電子郵件／密碼登入

Firebase Console > Authentication > Sign-in method > Email/Password > Enable。

## 4. 設定 Realtime Database Rules

在 Realtime Database > Rules 貼上以下規則。登入後的使用者都可以刪除整筆食材；但只有原認領人可以取消自己的認領，且食材分類只能使用頁面提供的五種分類。

```json
{
  "rules": {
    "bbq-items": {
      ".read": "auth != null",
      "$itemId": {
        ".write": "auth != null && (!data.exists() || !newData.exists() || data.child('claimedBy').val() == null || (newData.child('name').val() == data.child('name').val() && newData.child('claimedBy').val() == data.child('claimedBy').val() && newData.child('claimedByUid').val() == data.child('claimedByUid').val()) || (newData.child('claimedBy').val() == null && (data.child('claimedByUid').val() == auth.uid || data.child('claimedBy').val() == auth.token.name)))",
        ".validate": "newData.hasChildren(['name', 'claimedBy']) && newData.child('name').isString() && newData.child('name').val().length <= 30 && (!newData.hasChild('category') || (newData.child('category').isString() && (newData.child('category').val() == '肉類' || newData.child('category').val() == '蔬菜' || newData.child('category').val() == '烤肉用具' || newData.child('category').val() == '其他' || newData.child('category').val() == '甜點' || newData.child('category').val() == '甜'))) && (newData.child('claimedBy').val() == null || newData.child('claimedBy').isString()) && (!newData.hasChild('claimedByUid') || newData.child('claimedByUid').val() == null || newData.child('claimedByUid').isString())"
      }
    }
  }
}
```

## 5. 發布到 GitHub Pages

1. 建立 GitHub repository。
2. 上傳 `中秋烤肉登記.html`。
3. 在 repository 的 Settings > Pages，選 `Deploy from a branch`、`main`、`/ (root)`。
4. 儲存後等待 GitHub Pages 產生網址，再把網址傳給朋友。

若使用自訂網域，請在 Firebase Authentication > Settings > Authorized domains 加入該網域。
